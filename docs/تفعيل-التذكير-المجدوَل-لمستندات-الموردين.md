# تفعيل التذكير المجدوَل لمستندات الموردين

> **الحالة:** الكود منشور وجاهز. تبقّت خطوة إعداد واحدة في Cloudflare (أقل من 5 دقائق).
> **قبلها:** التذكير يعمل **يدويّاً** من زرّ «طلب تجديد» في اللوحة — لا شيء معطَّل.

---

## ماذا يفعل؟

يمرّ يوميّاً على الموردين المعتمدين ويُرسل بريد تجديد **في موعده تلقائيّاً**:

| الحالة | التذكير |
|---|---|
| تنتهي خلال ≤30 يوماً | مرّة واحدة (المرحلة `d30`) |
| تنتهي خلال ≤14 يوماً | مرّة واحدة (`d14`) |
| تنتهي خلال ≤7 أيام | مرّة واحدة (`d7`) |
| **منتهية** | كل أسبوعين حتى تُجدَّد |
| وثيقة ناقصة أو شهادة محتوى محلي بلا بيانات | شهريّاً |

**لا تكرار:** كل إرسال يُقيَّد في سجلّ التدقيق بوسم مرحلته، فلا يصل المورّد تذكيران
لنفس المرحلة مهما تكرّر تشغيل الكرون.

## الإعداد (خطوتان)

### ١) تأكّد من `CRON_SECRET`

```bash
curl -s https://suppliers.aldeyabi.com/api/doc-renew
```
إن كان `"cron_secret": true` فانتقل للخطوة ٢.
وإلّا: Cloudflare Pages → `aldeyabi-procurement` → Settings → Variables →
أضِف **`CRON_SECRET`** بقيمة عشوائية طويلة على **Production** ثم أعِد النشر.

> ملاحظة: هذا نفس المتغيّر الذي يستعمله عامل البوابة القائم — إن كان مضبوطاً فلا تُغيّره.

### ٢) أضِف مُشغِّل الكرون

**الأسهل:** إن كان لديك Worker باسم `portal-outbox-cron` فأنشئ **Worker ثانياً مستقلاً**
(لا تُعدّل القائم — البوابة نظام منفصل) بهذا المحتوى:

```js
export default {
  async scheduled(event, env, ctx) {
    await fetch('https://suppliers.aldeyabi.com/api/doc-renew?sweep=1', {
      method: 'POST',
      headers: { Authorization: 'Bearer ' + env.CRON_SECRET },
    });
  },
};
```

- أضِف سرّ الـWorker: `CRON_SECRET` = **نفس القيمة**.
- Cron Trigger: `0 6 * * *` (يوميّاً ٦ صباحاً UTC = ٩ صباحاً بتوقيت السعودية).

**بديل بلا Worker:** أي خدمة جدولة خارجية تستدعي:
`POST https://suppliers.aldeyabi.com/api/doc-renew?sweep=1`
بترويسة `Authorization: Bearer <CRON_SECRET>`.

## التحقّق

```bash
# استدعاء يدويّ للتجربة (نفس ما يفعله الكرون)
curl -s -X POST -H "Authorization: Bearer <CRON_SECRET>" \
  "https://suppliers.aldeyabi.com/api/doc-renew?sweep=1"
```

**المتوقّع أول مرّة:** `{"ok":true,"candidates":N,"sent":N,"failed":0}`
**وفي نفس اليوم مرّة ثانية:** `{"ok":true,"skipped":"throttled"}` ← الخانق يعمل.

**بلا مصادقة:** يجب أن يعيد **401**.

> لتجاوز الخانق أثناء التجربة فقط: أضِف `&force=1`.

---

## الضوابط المدمجة

- **سقف 40 رسالة لكل تشغيلة** (وتُكمَّل في اليوم التالي) — يحمي من دفعة ضخمة مفاجئة.
- **مباعدة 300ms** بين الرسائل (حدّ معدّل مزوّد البريد).
- **خانق 20 ساعة** — تشغيلة واحدة يوميّاً ولو نُودي كل دقيقة.
- **من بلا بريد صالح يُتخطّى بهدوء** (يبقى مرئيّاً في اللوحة للمتابعة اليدوية).
- كل تشغيلة تُقيَّد في سجلّ التدقيق (`action=sweep`) بعدد المرشّحين والمُرسَل والفاشل.

## الإيقاف

احذف مُشغِّل الكرون (أو عطّل الـWorker). النقطة تبقى موجودة لكنها لا تُنادى،
والتذكير اليدويّ من اللوحة يبقى يعمل كما هو.
